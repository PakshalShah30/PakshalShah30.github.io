04Building

Trowel for Salesforce.

An AI agent that reads a Salesforce org's metadata and produces the Well-Architected assessment consultancies bill five figures for. It's the answer I'm working out to a question I keep hitting at work: what does agentic AI look like inside a governed enterprise platform?

Personal project · in progress

What it does

github.com/PakshalShah30/trowel-for-salesforce ↗

Excavates an org's Flows, Apex, fields, and permission sets into a dependency graph, then an agent with hybrid retrieval (graph traversal for exact references, embeddings for semantics) finds dead automation, conflicting triggers, and permission sprawl. Findings are detected deterministically by graph queries; the language model explains and prioritizes them, but never discovers them. Every analysis path is gated by a golden-dataset eval suite in CI.

  • Structured Flow summaries via schema-forced model output

  • Hybrid retrieval, eval suite, agent loop, Well-Architected report
